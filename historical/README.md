# Historical source only

These are authored source snapshots and withdrawn prototypes, not player files.
The early Direct3D wrapper prototypes crashed and were withdrawn. Do not install
or package them. They are retained so community developers can inspect the
research and regressions without repeating the reverse engineering.

Use only the repository-root dev.py and aria-wide/src for current builds.
Historical build recipes may reference old SDK layouts; they are not supported
entry points. No binaries, game assets, private captures or saves are included.
