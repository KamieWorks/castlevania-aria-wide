# 晓月圆舞曲 16:9 DLL 补丁 v27

社区源码与开发说明：https://github.com/KamieWorks/castlevania-aria-wide 。克隆目录即 `DEV_ROOT`，包含完整补丁源码、调试工具、源码地图与可移植构建入口。

用于 Steam《Castlevania Advance Collection》中的《晓月圆舞曲》。补丁额外绘制地图与屏外精灵，输出 288×162 的 16:9 画面，保持原版像素比例；上下各一行留空。

大房间靠近左右边界时，新增视野自动向房间内部调整。角色位于房间最右端时，完整显示其左侧新增的 48 像素，避免房间外黑带占用视野。固定小房间默认保持原始居中画面。装饰扩展的完整实现仍保留，供未来开源实验使用，原版碰撞、活动区域和战斗边界保持不变。标题、菜单、结局插画保持原比例居中。

血条固定左上，道具／金钱通知固定左下，获得魂的短通知固定右上，GBA 原生敌人信息固定右下；说明弹窗保留居中布局。背景视差与裁切共同使用当前实际光栅的相机，消除接近房间边缘时因 RAM 提前更新一帧引起的 1～2 像素抖动。前景镜头停止后，背景停止继续跟随，水面等时间动画继续播放。月亮前的半透明云单独按原生 1/12 视差补偿，保留缓慢自主飘动，避免镜头到边缘时云被额外拖动。

## 安装与回滚

1. 关闭游戏，将 `d3d9.dll` 放入与 `game.exe` 相同的目录，再从 Steam 正常启动。
2. `AriaWide.ini` 为可选配置。`ExtendFixedRooms` 默认及当前安装值均为 `0`，固定房间保持原始画面；实验者可设为 `1` 重新启用装饰扩展。大房间宽屏始终保留。删除配置也默认关闭装饰扩展。
3. 完全卸载时，关闭游戏并移走本补丁的 DLL 与可选配置即可。如果目录已有其他来源的同名 DLL，应先备份原文件。

玩家只需要 DLL，无需 Python、Frida、注入器或逆向工具。补丁不改磁盘 EXE、ROM 和游戏素材；保留原生存档、倒带、合集菜单和成就接口。调试用的静音、隐藏窗口与存档写入隔离不会进入玩家补丁。

## 验证范围

v27 修复尤里乌斯模式副武器 OBJ 图标和边框的屏幕锚定。存档 2 的四种副武器在房间左端、中部、右端及读档后，日文原版和汉化版分别通过 49 帧独立原生图标像素对照；两版本另各通过连续行走的 144 帧密集边缘采样。日文原版同时核对血条、MP 条及 HP 数字，全部匹配。两轮正常退出、真实存档哈希不变。v26 的云层和此前渲染路径保留；本轮没有重跑全部历史场景。

本轮从存档 1 进入用户指定的月亮与云房间，检查左右移动及静止的 288 个连续帧，抽样 42,125 个可见云像素与独立原生合成参考全部一致。另以原生提示图块核对四角布局及居中说明，共三种视野位置、十二组布局；按用户要求，未实际刷取道具／金钱或魂，自然获取事件由用户测试。边缘验证在两个实际房间持续行走，四组各连续采样 96 帧，覆盖两端及半速背景，并检查水面动画。另检查固定房间、边缘视野、屏外精灵、混帧、仿射、倒带和菜单恢复。HUD 与背景在需要时会重新绘制；不能再将整块中央画面描述为未修改的原版像素。具体二进制与验证证据见 `VALIDATION.zh-CN.md`。

此前 v20 通过九项串行回归，以及额外 24 个 Boss Rush 场景的 72 个进入、动作和恢复采样。这些属于此前版本的证据，没有将该 24 场景在 v26 重新逐个运行。

此前实现还完成 342 个地图房间的原生进入与绘制检查、真结局完整字幕返回片头、普通及 Julius 结局重放、晓月与白夜实际切换、初始化失败回滚、多次冷启动和退出、20 分钟持续运行及原生 D3D9 Reset 检查。各轮所用版本和证据边界见 `VALIDATION.zh-CN.md`；房间绘制检查不等于逐个 Boss 完整通关。

## 独立构建

需要 Windows、Visual Studio C++ x86 工具链和 Windows SDK：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

输出为 `build\d3d9.dll`。使用静态 C/C++ 运行库，不需要额外 VC 运行库 DLL。MinHook 固定版本及完整许可证已包含在源码中，构建无需联网下载依赖。

```powershell
powershell -ExecutionPolicy Bypass -File .\package.ps1
```

默认输出两文件的精简玩家包到上级 `deliverables`：`d3d9.dll` 与合并完整第三方许可的 `README.txt`。可添加 `-IncludeSource` 另行生成构建源码归档；完整开发工具的 Git 整理独立维护。归档不包含游戏资源、私有快照、用户存档或运行时调试模块。第三方许可见 `THIRD-PARTY.md` 和 MinHook 许可证。
